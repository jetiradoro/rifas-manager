# Directorio .claude

Este directorio contiene toda la configuración y documentación para Claude Code al trabajar en este repositorio.

## Punto de Entrada Principal

- **[CLAUDE.md](CLAUDE.md)** - **LEER PRIMERO**: Archivo principal con conocimiento esencial del proyecto, reglas de comportamiento y comandos principales.

## Documentación Detallada

Consultar estos archivos para información específica y ampliada:

- **[knowledge.md](knowledge.md)** - Arquitectura, stack tecnológico y estructura del proyecto
- **[rules.md](rules.md)** - Reglas de código, convenciones y commits
- **[commands.md](commands.md)** - Comandos de desarrollo, Docker, Prisma, Git y troubleshooting
- **[database.md](database.md)** - Prisma: schema, migraciones, relaciones y queries
- **[behavior.md](behavior.md)** - Patrones de código backend y frontend

## Uso

1. **Empezar por**: [CLAUDE.md](CLAUDE.md) - Contiene el conocimiento esencial
2. **Profundizar en**: Los archivos específicos según la necesidad
3. Claude Code lee automáticamente estos archivos para entender mejor el proyecto y seguir las convenciones establecidas
